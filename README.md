# Alassmaa Media

Run `npm install` then `npm run dev` and open http://localhost:3000. Run `npm run build` before deployment.

The logos are derived from the supplied brand board. Replace the sample portfolio visuals and case studies with licensed company work. External demo photography loads from Unsplash; replace URLs with owned files in `public/` for production. The enquiry button opens the visitor's email application; add a receiving address via `NEXT_PUBLIC_CONTACT_EMAIL` and optionally a WhatsApp number via `NEXT_PUBLIC_WHATSAPP_NUMBER` (digits including country code) in `.env.local`. There is no server database or CMS yet. Update company details and licensed services before publishing.

The primary CTA and theme switch take interaction inspiration from Uiverse submissions by Shashvhat and TahaShameli; they were rebuilt as semantic accessible controls. See `THIRD_PARTY_NOTICES.md`.
